# 第9章 Protégé 入门

## 第2篇 安装与创建新本体

### 下载安装 Protégé（含 JRE 要求）

**系统要求：**
- Java Runtime Environment (JRE) 8 或更高版本
- 支持 Windows、macOS 和 Linux

**下载：**
从官方网站 [protege.stanford.edu](https://protege.stanford.edu/) 下载最新版本。

### 创建新本体：URI 设置与语言选择

**创建步骤：**
1. 打开 Protégé，点击 `File > New Project`
2. 输入本体 URI（推荐格式：`http://example.org/ontology/myOntology`）
3. 选择本体语言（OWL、RDF 等）
4. 点击 `Create` 完成初始化

### 本体元数据设置

设置本体的基本信息：
- **Creator**：本体创建者
- **Version Info**：版本信息
- **Annotation Properties**：注释属性
