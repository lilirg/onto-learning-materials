# 第9章 Protégé 入门

## 第3篇 添加类与属性

### 添加类、对象属性、数据属性

**添加类：**
1. 点击 `Classes` 标签页的 `+` 按钮
2. 输入类名（如 `Person`、`Animal`）
3. 设置父类关系

**添加对象属性：**
1. 点击 `Object Properties` 标签页
2. 定义属性名称（如 `hasParent`）
3. 设置属性特征（传递性、对称性等）

**添加数据属性：**
1. 点击 `Data Properties` 标签页
2. 定义属性名称（如 `hasAge`、`hasName`）
3. 设置值的数据类型（xsd:integer、xsd:string 等）

### 设置类层次结构与属性特征

- 使用 `Equivalent To` 设置等价类
- 使用 `Disjoint With` 设置不相交类
- 设置属性域（domain）和范围（range）
