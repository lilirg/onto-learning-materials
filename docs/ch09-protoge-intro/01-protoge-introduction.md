# 第9章 Protégé 入门

## 第1篇 Protégé 简介与界面概览

### Protégé 简介与界面概览

Protégé 是由斯坦福大学医学院和 SLIPCYRE 项目开发的开源本体编辑工具。

**主要特性：**
- 支持 OWL、RDF、RDFS 等多种本体语言
- 可视化的本体编辑器
- 内置推理器支持
- 插件系统可扩展功能

**应用领域：**
- 生物医学本体建模
- 知识图谱构建
- 语义网数据开发

### 界面组件

- **Classes 标签页**：管理和编辑类层次结构
- **Object Properties**：定义类之间的关系属性
- **Data Properties**：定义实体的数据属性
- **Individuals**：创建和编辑类的实例
- **Axioms**：查看和编辑本体公理
