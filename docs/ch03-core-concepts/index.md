- [3.2 本体类型层次](./02-ontology-types.md) — 掌握上层本体、领域本体与任务本体的分类体系和应用场景
- [3.3 分类法与本体的对比练习](./03-comparison-exercise.md) — 通过 RDFS 建模与 OWL 本体对比，展示本体表达力的优势
