# 第3章 核心概念体系

## 第2篇 本体类型层次（上层/领域/任务）

### 上层本体（Upper Ontology）

上层本体描述最通用的概念，不局限于特定领域：
- **BFO（Basic Formal Ontology）**：基本形式本体
- **DOLCE**：描述逻辑本体
- **SUMO（Summit Ontology）**

### 领域本体（Domain Ontology）

领域本体专注于特定知识领域：
- **Gene Ontology (GO)**：基因和蛋白质功能
- **SNOMED CT**：临床医学术语
- **FIBO**：金融信息

### 任务本体（Task Ontology）

任务本体描述特定任务相关的概念：
- 诊断流程
- 工作流建模
- 问题分析方法
