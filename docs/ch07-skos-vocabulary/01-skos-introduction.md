# 第7章 SKOS 词汇构造

## 第1篇 SKOS 简介与基本概念

### SKOS（Simple Knowledge Organization System）简介

SKOS 是 W3C 推荐标准，用于表示词汇表（主题词表、分类法、词库等）。

### 设计目标与适用场景

- 将现有词汇表发布为 RDF
- 与 RDFS 和 Dublin Core 兼容
- 支持语义网应用

### 核心概念

SKOS 定义了三种核心资源：
- **Concept（概念）**：信息领域中关于某个主题的想法
- **Concept Scheme（概念体系）**：概念的组织结构
- **Label（标签）**：概念的人读名称
