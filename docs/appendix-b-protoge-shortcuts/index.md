# 附录 B: Protégé 快捷键

## Protégé 常用快捷键

### 基础操作

| 快捷键 | 功能 |
|--------|------|
| Ctrl+N | 新建本体 |
| Ctrl+O | 打开本体 |
| Ctrl+S | 保存本体 |
| Ctrl+Shift+S | 另存为 |
| Ctrl+Z | 撤销 |
| Ctrl+Y | 重做 |

### 编辑操作

| 快捷键 | 功能 |
|--------|------|
| Ctrl+Insert | 复制所选 |
| Ctrl+Insert | 粘贴 |
| Delete | 删除所选 |
| F2 | 重命名所选 |
| F4 | 编辑属性 |

### 导航操作

| 快捷键 | 功能 |
|--------|------|
| Ctrl+Tab | 切换标签页 |
| Ctrl+Shift+P | 命令面板 |
| Ctrl+F | 搜索 |
| F5 | 刷新视图 |
