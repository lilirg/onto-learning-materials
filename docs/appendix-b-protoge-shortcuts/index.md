# 附录 B: Protégé 快捷键参考

## 基本操作

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + N` | 创建新本体 |
| `Ctrl + O` | 打开本体 |
| `Ctrl + S` | 保存本体 |
| `Ctrl + Shift + S` | 另存为 |
| `Ctrl + Z` | 撤销 |
| `Ctrl + Y` | 重做 |

## 编辑操作

| 快捷键 | 功能 |
|--------|------|
| `Delete` | 删除选中项 |
| `F2` | 重命名 |
| `Ctrl + A` | 全选 |
| `Ctrl + C` | 复制 |
| `Ctrl + V` | 粘贴 |
| `Ctrl + X` | 剪切 |

## 推理操作

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + R` | 运行推理器 |
| `Ctrl + Shift + R` | 检查一致性 |
| `Ctrl + Shift + C` | 分类本体 |

## 导航操作

| 快捷键 | 功能 |
|--------|------|
| `F3` | 查找类 |
| `Ctrl + F` | 查找文本 |
| `Ctrl + +` | 放大 |
| `Ctrl + -` | 缩小 |
