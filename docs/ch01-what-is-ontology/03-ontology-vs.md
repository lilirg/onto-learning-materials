# 第1章 什么是本体

## 第3篇 本体 vs 数据库 vs 词汇表

### 本体 vs 数据库 vs 词汇表 vs 分类法

| 特性 | 数据库 | 词汇表 | 分类法 | 本体 |
|------|--------|--------|--------|------|
| 数据结构 | 表格 | 列表 | 树状层级 | 图结构 |
| 语义表达 | 有限 | 简单 | 层级关系 | 丰富语义 |
| 推理能力 | 无 | 无 | 有限 | 强推理 |
| 关系表达 | 主外键 | 无 | is-a | 多类型关系 |

### 为什么形式化是本体的本质特征

本体的核心价值在于其**形式化表达**能力，这使得机器能够理解并推理知识。

- **形式化**：使用形式逻辑语言描述
- **显式**：概念和关系明确定义
- **共享**：共识性的知识表示
