# 第1章 什么是本体

## 第1篇 概述：从知识库到本体

### 从知识库到本体：为什么我们需要本体

在知识管理和语义网领域，本体（Ontology）是一个核心概念。本章将深入探讨本体的定义、组成和应用场景。

### 本体的核心组成预览

一个完整的本体包含以下核心要素：
- **类（Class）**：抽象的类别或概念
- **属性（Property）**：描述类的特征或类之间的关系
- **实例（Individual）**：具体的对象或实体
- **公理（Axiom）**：关于类、属性和实例的断言

### 本体的应用场景一览

本体现在广泛应用于：
- 知识图谱构建
- 生物医学信息学
- 企业知识管理
- 自然语言处理
- 智能推荐系统
