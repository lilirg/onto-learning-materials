# 第1章 什么是本体

## 第2篇 核心定义与组成

### Gruber 的本体定义解析

Tom Gruber 给出了最著名的本体定义："A formal, explicit specification of a shared conceptualization."

### 本体的学术定义与实际意义

本体学（Ontology）在哲学中研究"存在"的本质，在计算机科学中则被应用于知识表示。

### 核心定义：类、属性、实例、关系、公理、规则

一个完整的本体包含以下核心要素：
- **类（Class）**：抽象的类别或概念
- **属性（Property）**：描述类的特征或类之间的关系
- **实例（Individual）**：具体的对象或实体
- **关系（Relation）**：类与类、类与实例之间的语义关联
- **公理（Axiom）**：关于类、属性和实例的形式化断言
- **规则（Rule）**：推导新知识的逻辑规则
