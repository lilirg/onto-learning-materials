# 附录 E：Pizza Ontology 教程指引

Pizza Ontology 是一个经典的用于学习OWL本体的示例本体。

## 简介

Pizza Ontology 定义了一种披萨的完整词汇，包括：

- 各种披萨类型
- 配料（ingredients）
-  crust 类型
- 地区风格（如 NAPLES 风格）

## 学习目标

通过这个教程，你将学习：

1. 如何使用 Protégé 创建本体
2. 如何定义类和属性
3. 如何添加公理和约束
4. 如何使用推理器进行检查
