# 附录 C: 本体仓库与资源

## 常用本体仓库

### 公开本体仓库

- [OBO Foundry](https://obofoundry.org/) - 开放本体的协作资源
- [BioPortal](https://bioportal.bioontology.org/) - 生物医学本体仓库
- [LOD Cloud](https://lod-cloud.net/) - 链接开放数据云
- [Schema.org](https://schema.org/) - 网络数据模式
- [DBpedia](http://dbpedia.org/) - 结构化维基百科数据

### 工具与平台

- [Protégé](https://protege.stanford.edu/) - 本体编辑器
- [TopBraid](https://www.topquadrant.com/) - 企业级 RDF 工具
- [Apache Jena](https://jena.apache.org/) - RDF 和语义网框架
